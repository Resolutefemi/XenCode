# Appearance and Language

On the "Settings" home page, tapping "Theme", "Background image", or "Language" opens a bottom sheet; the choice takes effect immediately and is saved.

## Theme

The sheet has three sections: light/dark mode, color scheme, and Monet colors. It does not close automatically after a selection, making it easy to compare several schemes in a row.

### Light/dark mode

Pick one of three: follow the system, fixed dark, or fixed light.

### Color schemes

Four presets, each with its own light and dark variants:

- **Default Blue**: the historical default blue tone.
- **Coffee**: warm terracotta with an off-white paper-like base; the factory default, in effect when no theme has ever been selected.
- **Graphite**: neutral cool gray with minimal color distraction.
- **Forest**: low-saturation green.

The outer ring of each swatch is the theme's page background and the inner ring its primary color; the preview follows the current light/dark mode.

Git lane colors, log level colors, and the red/green of diff additions and deletions are functional indicators — they do not change with the theme, so the same meaning never gets different colors under different themes. Syntax highlighting in the code editor and terminal colors are separate settings of their own.

### Monet colors

When enabled, colors are extracted from the system wallpaper and the color scheme chosen above no longer applies (the swatches turn gray). Off by default.

Requires Android 12 or later; on older devices the toggle is unavailable and the description says so. The wallpaper palette is generated by the system and varies a lot across vendors — if you do not like the result, just turn it off.

## Custom background image

You can set a global background image:

- **Choose image**: pick one from the system gallery as the app-wide background, layered over every page's content (watermark effect, does not intercept touches). The terminal page stays pure black and does not show the background.
- **Opacity**: the slider shows 0% to 100%, but the effective range maps to 0% to 20% (so 100% on the slider means 20% opacity), keeping text readable at all times. Defaults to 15%; dragging applies live.
- **Remove background**: restores the default solid background.

The background image is stored in the app's private directory and is **not included in backups**, so it must be set up again when you switch devices.

## Language

It can follow the system language, or you can pin one of the supported languages directly.

## Terminal appearance

The terminal's color theme, font, font size, and cursor style are a separate set of settings; see [Terminal](/guide/terminal#appearance-settings).
